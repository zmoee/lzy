# 蓝奏云（woozooo）接口清单

## 0. 登录结论

**凭据可用，登录成功。**

| 项 | 实测值 |
|---|---|
| 账号 | `<自己的手机号>` |
| uid | `<自己的 uid>` |
| 主分享域 | `https://<你的域名>.lanzn.com` |
| 备用分享域 | `https://<备用域名>.lanzn.com`（domainid `<id>`） |
| 根目录 | 2 个文件夹 / 18 个文件（实测时刻） |
| 登录耗时 | 单次 POST 即返回 zt=1，无短信/图形验证码 |

前置有一层阿里云 ESA 的 JS 挑战（`acw_sc__v2`），不解决它任何 woozooo 页面都只返回 4KB 的混淆脚本。解法见 `acw.py`（固定置换表重排 + 固定 key 逐字节异或）。

## 1. 登录链路

```
GET  https://accounts.woozooo.com/accounts.php?action=login&ref=up.woozooo.com
     → 命中 ESA 挑战 → 计算 acw_sc__v2 写入 cookie → 重放 → 得到真实登录页
POST https://accounts.woozooo.com/accounts.php
     Content-Type: application/x-www-form-urlencoded
     task=uselogin&username=<账号>&password=<密码>&ref=up.woozooo.com
     → {"zt":1,"msgs":"https://up.woozooo.com/acc.php?t=<一次性令牌>","usename":""}
GET  <msgs>            ← 必须跟随，用于在 up.woozooo.com 建立会话
     → 之后 doupload.php / html5up.php 全部可用
```

要点（均已实测）：

- 密码**明文提交**，无 hash、无签名、无验证码。
- `ref` 必填为 `up.woozooo.com`。
- 返回的 `t` 令牌**一次性**：重放同一个链接得到标题为「登录过期.」的页面。
- 失败时 `zt=0`，`msgs` 为中文错误文案（如「账号或密码错误」）。

## 2. Cookie 清单

| Cookie | 域 | 作用 |
|---|---|---|
| `phpdisk_info` | .woozooo.com | 核心会话票据，**鉴权唯一凭据** |
| `lanzou_ifo` | .woozooo.com | 同上（二进制流用同值副本） |
| `ylogins` / `ylogin` | .woozooo.com | 会话签名 / uid=`<你的 uid>` |
| `uag` | .woozooo.com | 客户端指纹标记 |
| `PHPSESSID` | 各站 | PHP 会话 |
| `acw_tc` / `cdn_sec_tc` / `acw_sc__v2` | 各站 | ESA 风控 |

**接口鉴权只认 cookie**：实测删除 `uid` 查询参数、删除 `vei`、把 `vei` 改成任意值 `AAAA`，`task=5` 依然返回完整数据。

## 3. 后台接口总表

统一入口：`POST https://up.woozooo.com/doupload.php`，`application/x-www-form-urlencoded`，用 `task` 区分功能。
列表接口可附加 `?uid=<你的 uid>` 与表单参数 `vei=<页面内 token>`，二者**非必需**（页面 `mydisk.php?item=files&action=index` 内联 JS 提供 vei）。

响应统一结构：`{"zt":..,"info":..,"text":..,"dat":null}`。

### 3.3 上传接口（实测通过）

```
POST https://up.woozooo.com/html5up.php       multipart/form-data
字段: task=1, vie=2, ve=2, folder_id=-1
文件: upload_file=<文件>                        (WebUploader fileVal)
→ {"zt":1,"info":"上传成功","text":[{icon,id,f_id,name_all,name,size,time,downs,onof,is_newd,...}]}
```

- 单文件上限实测环境 `upsizeb=104857600`（100M），单次总配额 `fsizeall`（页面变量，约 1.16G）。
- 允许扩展名白名单在页面内声明（apk/zip/rar/txt/7z/docx/pdf/mp3/mp4/png… 等约 120 种），服务端另有校验。
- `zt=9` 表示未登录（会话失效）；`zt=0` 为失败。

## 4. 状态码语义

| `zt` | 含义 |
|---|---|
| `1` | 成功（`47` 在根目录、`49 type=1` 也用 1） |
| `0` | 业务失败，`info` 为中文原因（权限不足 / 参数错误 / 重复操作） |
| `2` | 部分接口的特殊分支：`41`、`39` 表示会员限制；`47` 表示「已进入某目录」 |
| `null` | `16`、`59` 等在会员校验失败时返回空 zt + 提示文案 |
| `9` | 上传接口专属：未登录 |

## 5. 明确未验证的部分

- 写类且会改动账号状态的接口未执行：`38/40/43/48/49(type=2)/51/58/59`、回收站全部 action。
- 分享页下载端（分享域的 iframe `ajaxm.php` 取真实下载直链）本轮未逆向，`task=31` 实测返回「未开放」，需要走分享页二次解析。
- 会员类能力（改名、缩略图、自定义外链、关闭文件夹密码）在免费账号上只能拿到限制提示，未能验证成功态响应结构。

## 6. 文件与用法

| 文件 | 作用 |
|---|---|
| `acw.py` | ESA `acw_sc__v2` 挑战计算（含自检） |
| `lanzou.py` | 会话层：登录、挑战重放、cookie 持久化 |
| `lanzou_api.py` | **接口封装 SDK**，覆盖上表全部已实测接口，`python lanzou_api.py` 跑自检 |
| `probe_login.py` / `probe_js.py` | 首轮探测：登录页表单与内联 JS（已被 fetch_* 取代） |
| `probe_api.py` / `probe_read.py` / `probe_write.py` / `probe_extra.py` | uid/vei 依赖、只读、写闭环、短链补测 |
| `fetch_pages.py` / `fetch_assets.py` / `fetch_comm.py` | 页面与 JS 落地到 `raw/`（含 `raw/js/comm.js` — 全部接口的原始定义） |
| `cookies.json` | 登录态缓存（含有效 `phpdisk_info`，**等同账号凭据**） |

```python
from lanzou_api import Lanzou

lz = Lanzou.login("<账号>", "<密码>")   # 或 Lanzou.from_cookies()
for f in lz.folders():                       # task=47
    print(f["fol_id"], f["name"])
for f in lz.files():                         # task=5
    print(f["id"], f["name_all"], f["size"])
info = lz.file_info(319725286)               # task=22 → 分享短码
print(info["is_newd"], info["f_id"], info["pwd"])
```
